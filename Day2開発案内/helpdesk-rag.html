クラウド利用: Watson Machine Learning（watsonx.ai Runtime）/ watsonx.ai Studio / Cloud Object Storage　ローカルVector DB: Chroma

文書状態現行構成
利用目的学生向け演習・検証
アプリ実行場所Mac／Windows
利用期間2026/10/10～12/31
IBM Cloudへアプリケーションをデプロイする必要はない。学生端末でヘルプデスクRAGサンプルアセットとChromaを実行し、Watson Machine Learning（watsonx.ai Runtime）の生成／Embedding APIへ接続する。FastAPIはサンプルアセットのAPI実行技術である。watsonx.ai StudioとCloud Object StorageはProject管理・関連ストレージであり、通常のRAGリクエスト経路には置かない。アプリはlocalhost限定で、LANやInternetからのInbound公開を行わない。

データと保持

  • 教材では架空Ticket・架空社内文書だけを利用
  • ChromaにはVector、Chunk、検索用metadataをローカル保存
  • 文書削除時はChunk・Vector・cacheも削除
  • Prompt、Ticket本文、生成全文を標準ログへ出さない
  • 利用終了時はdata/runtimeとdata/indexを削除

運用と責任分界

  • 運営: IBM Cloud、IAM、予算、Key失効
  • 学生・教員: localhostアプリ利用と成果物管理
  • 検索文書変更時はbuild_index.pyでChromaインデックスを再構築
  • 模擬LLM／NumPy検索は接続不要の動作確認・テスト用

利用前に確定する値

  • IBM Cloud Region、Project ID、料金プラン
  • watsonx.ai Projectと既存instance再利用の有無
  • 利用者数、演習日数、1人あたりAPI回数
  • 生成／Embedding Model IDとVector次元
  • Chroma collection名とローカル保存先
  • 利用者数、期間、rate limit、予算上限

実行条件

  • 実行環境: Python 3.14
  • IBM Cloudへのアプリ配備は今回の必須範囲外
  • Python直接実行を標準とする
  • Vector DBはローカルChromaを標準とする
  • Docker／Podmanは任意。Python直接実行で代替可能

RAG 回答生成フロー（POST /answers/draft）
# 処理 呼び出し先 備考
1 リクエスト検証 DraftAnswerRequest ticket_id XOR question (oneOf)。両方 / 両方なし → 422
2 Ticket 取得 (ticket_id 指定時) TicketService.get_ticket() 存在しない ID → 404
3 Query を Vector 化 EmbeddingPort.encode_query() 標準: WatsonxEmbeddingAdapter / 代替: MockEmbeddingAdapter
4 Vector 検索 VectorStorePort.search(access_scope) Chromaでis_active=trueを適用し、APIでdocument_typesが指定された場合はmetadataで絞り込む。Adapterはaccess_scopeにも対応するが、現行APIからは指定しない。NumPyは接続不要のテスト用
5 スコア閾値フィルタ RagService VECTOR_MIN_SCORE 未満を除外。0 件 → LLM を呼ばず insufficient_context 返却
6 Prompt 組み立て RagService [S1]…[Sn] allow-list を生成。system + user メッセージ
7 LLM 呼び出し LLMPort.generate(messages) 標準: WatsonxLLMAdapter (retry 最大 2 回) / 代替: MockLLMAdapter
8 JSON パース RagService Markdown fence除去とJSON候補抽出を行う。構造化結果を取得できない場合は生成textを要手動確認の回答案として扱う
9 Citation allow-list 検証 RagService LLM の citation_ids を allow-list で検証。chunk_id / score / source をサーバー側 metadata から付加
10 レスポンス返却 DraftAnswerResponse needs_human_confirmation=true固定。Provider固有のresponse objectは返さない。JSON解析失敗時は生成textを回答案として返す
