# メール転記スプシ → RAG アプリ 連携手順

メール転記用の GAS（`gmail_inquiry_apps_script.txt`）に `doGet` を足して、
RAG アプリが1分ごとにスプシの行を読み、新しい受付番号だけをチケットとして追加する。

- スプシは**読むだけ**。アプリで付けた分類・ステータスはスプシに書き戻さない
- 合言葉を知っている人は誰でもスプシの中身を読めるので、URL と合言葉は人に渡さない・git に入れない

## 0. メール転記の GAS を先に動かす

`メール自動登録作成手順/` の手順書どおりに、`gmail_inquiry_apps_script.txt` をスプシの Apps Script に貼り、
`FOLDER_ID` の設定と `setupTrigger` の実行まで済ませる（テストメールがスプシに入ることを確認する）。

## 1. GAS にコードを足す

メール転記スクリプトを貼ったのと同じ Apps Script の末尾に、次を追加する。
`SYNC_TOKEN` は自分で決めた長いランダム文字列にする（例: パスワード生成ツールで 32 文字）。

```javascript
// ===== RAG アプリ連携（読み取り専用） =====
const SYNC_TOKEN = 'ここに合言葉を入力';

function doGet(e) {
  const token = e && e.parameter ? e.parameter.token : '';
  if (!token || SYNC_TOKEN.startsWith('ここに') || token !== SYNC_TOKEN) {
    return syncJson_({ error: 'unauthorized' });
  }
  const sheet = getSpreadsheet().getSheetByName(CONFIG.SHEET_NAME);
  const range = sheet.getDataRange();
  const values = range.getValues();
  const rich = range.getRichTextValues();  // 添付画像セルのリンクを読むため
  const headers = values.shift();
  rich.shift();
  const imageCol = headers.indexOf('添付画像');
  const rows = values
    .map((r, ri) => {
      const row = Object.fromEntries(
        headers.map((h, i) => [h, r[i] instanceof Date ? r[i].toISOString() : r[i]])
      );
      row['添付画像URL'] = imageCol < 0 ? [] : rich[ri][imageCol].getRuns()
        .map(run => run.getLinkUrl())
        .filter(Boolean);
      return row;
    })
    .filter(row => row[headers[0]]);
  return syncJson_({ rows });
}

function syncJson_(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## 2. ウェブアプリとしてデプロイ

1. Apps Script 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車）→「ウェブアプリ」
3. 次のユーザーとして実行: **自分**
4. アクセスできるユーザー: **全員**（合言葉で守る）
5. 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

コードを直したときは「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新する（URL は変わらない）。

## 3. 動作確認（ブラウザ）

`<URL>?token=<合言葉>` を開いて `{"rows":[...]}` が出れば OK。
合言葉なしで開くと `{"error":"unauthorized"}` になる。

## 4. アプリの `.env` に追記

```
SHEET_SYNC_URL=https://script.google.com/macros/s/xxxxx/exec
SHEET_SYNC_TOKEN=（手順1で決めた合言葉）
SHEET_SYNC_INTERVAL_SECONDS=60
```

`make dev` を再起動すると、ログに `Sheet sync enabled: interval=60s` が出る。
新しい行を取り込むと `Sheet sync: added=1 skipped=0` が出る。

## 取り込みのルール

| スプシの列 | チケット |
|---|---|
| 受付番号 | ticket_id（既にあれば追加しない＝上書きしない） |
| 受付日時 | created_at |
| お客様名 / メールアドレス / 注文番号 | 同名（LLM には渡さない） |
| 商品名 | product_name |
| 問い合わせ内容（要約）※中身はメール本文全体 | description（4000字まで） |
| 添付画像 | 空でなければ has_attachment = true |
| 添付画像のリンク（`添付画像URL`） | Google ドライブのファイルIDだけを attachment_file_ids に保存（ドライブ以外のURLは捨てる）。画面のサムネイル表示に使う |
| ステータス | status（空なら「未対応」） |

カテゴリ・緊急度などは取り込まない（担当者がアプリで分類案を適用して決める）。
メールアドレスの形式が不正などの行は飛ばし、ログには行番号だけを出す。

## 添付写真の表示について

写真は Google ドライブに非公開のまま保存され、アプリの画面は**ブラウザがログインしている Google アカウントの権限**でサムネイルを読み込む。
見る権限がない人には、写真の代わりに「ドライブで開く」リンクが出る。
「リンクを知っている全員に公開」にはしない（お客様の写真がネットに出るため）。
